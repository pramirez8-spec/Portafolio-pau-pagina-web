DESCRIPCIÓN DEL PROYECTO
--------------------------
Este proyecto consiste en el desarrollo de mi identidad visual
y portafolio personal como estudiante de Publicidad y Marketing
Digital. El objetivo principal fue construir una marca personal
sólida que refleje mis habilidades en diseño, creatividad y
estrategia digital.

A través de una propuesta estética moderna y coherente, se diseñó
una página web que integra elementos gráficos, tipografía y color
para comunicar de manera clara quién soy, qué hago y cómo puedo
aportar valor a las marcas.
